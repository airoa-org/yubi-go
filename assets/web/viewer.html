YUBI Go · Viewer

Copy to a computer

Copies every finished episode that is not there yet. Run it again later to fetch only the new ones.





  

  
  
  
  

  

    
On the headset

    
Uses the headset's cores for a while, and stops if recording starts. The dataset then waits under LeRobot exports, to download.

    
  

  

    
On a computer

    
Faster, and the headset stays free. Needs Rust, Python 3, ffmpeg with libx264 (on a Mac: brew install ffmpeg) and a clone of github.com/airoa-org/yubi-go. Run this in the clone: it copies the selected episodes into ~/yubi-go/episodes, builds yubi-export, and writes the dataset to ~/lerobot. The clone's docs/lerobot-export.md has the details.
